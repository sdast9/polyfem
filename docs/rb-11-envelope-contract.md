# RB-11 — Physical-envelope contract (declared before the matrix ran)

Written 2026-09-13 on PolyFEM `ce7c88b4b` plus the two working-tree changes
this stage forced before any matrix run (the time-dependent
`LinearElasticity` crash and the ignored `time/quasistatic` in the linear
formulation, see the record), IPC `bb795446`, PolySolve `ee5b296a`. The
thresholds below come from what each reference can resolve, not from
observed solver output; a failed threshold stays failed unless a separately
justified revised protocol is recorded in the validation record. This stage
characterises; it selects no element, quadrature, material or default.

## Scope and quantities

All runs are synthetic, public, single-threaded, quasistatic, one step,
`E = 1e6`, `rho = 1000` (SI), the `NeoHookean` law (`W = μ/2(‖F‖² − 3 − 2 ln J)
+ λ/2 ln² J`) or `MaterialSum(NeoHookean, HGODispersion)`, P1/P2 Lagrange
tetrahedra from a Kuhn subdivision (6 tets per cell). Meshes and scenes are
generated by `tools/rb11/envelope.py`.

| Symbol | Definition | Source |
| --- | --- | --- |
| `u_y,tip` | vertical displacement at the free-end centre `(L, H/2, W/2)` of the cantilever (a vertex of every mesh) | `solution` at the nearest output point |
| `r` | `u_y,tip / u_y,tip,ref` — the tip ratio to the converged reference; `r < 1` = the coarse space is too stiff (locking) | derived |
| `σ` | Cauchy stress at the output points (`cauchy_stess_*`), its uniformity (max deviation from the mean) | VTU |
| `l` | lateral stretch `1 + ū_x` on the face `x = 1` of the compressed cube | VTU |
| `κ(K)` | `λ_max / λ_min` of the reduced linear-elastic stiffness matrix (Dirichlet rows removed; dense symmetric eigenvalues) — at `F = I` the Neo-Hookean tangent is the linear-elastic operator, so this is the first Newton system's conditioning exactly | `output/data/stiffness_mat` of the `LinearElasticity` twin |
| cost | Newton iterations, wall time, DOF count | `out.json` `solver_info`, runner |

## Benchmarks

**Cantilever (locking, thin, distorted, fibre-reinforced).** `[0,4]×[0,H]×[0,W]`
clamped on `x = 0`, uniform body load `f_y = −ρ · rhs_y` with `rhs_y = .0104 H²`
(tip deflection ≈ 1e-3 L: linear regime, so the P1/P2/reference comparison
is a discretisation statement, not a large-strain one). The reference is
the same law and load on P2 with `h = .125` (32×8×8 cells, 63k DOF) for
`H = 1`, and on P2 64×4×4 cells for the thin sections; Euler–Bernoulli +
Timoshenko (Cowper's shear coefficient) is the analytical control for the
references, not the reference itself (3D elasticity, the clamped-end
constraint and the Poisson effect are not in beam theory).

**Compressed cube (homogeneous near-incompressibility).** Unit cube, symmetry
planes `u_x = 0` on `x = 0`, `u_y = 0` on `y = 0`, `u_z = 0` on `z = 0`,
`u_z = −.1` on `z = 1` (`l_z = .9`); the exact solution is the homogeneous
uniaxial state of `tools/rb09/reference.py` (`P_xx = 0` bisected to 1e-15),
which lies in the P1 space of every mesh. Exercises the law's
near-incompressible limit and the solver's conditioning without any
locking.

**Affine cube (anisotropy).** Unit cube with every face prescribed
`u = (F − I) X`, `F = [[1.10, 0, .03], [0, .96, 0], [0, 0, .97]]`; the exact
solution is the affine field on any mesh. The reference Cauchy stress is
`J⁻¹ P Fᵀ` with `P = ∂ψ/∂F` by central differences (`h = 1e-6`, relative
truncation ~1e-11) on the law as written in `HGODispersion.hpp`
(`E4 = κ I1 + (1 − 3κ) I4 − 1`, logistic switch `k_χ = 100`, normalised
fibre) plus the Neo-Hookean part.

## Declared thresholds

| Id | Check | Threshold | Justification |
| --- | --- | --- | --- |
| C-R | every run exits 0 with output; every linear twin's stiffness has `λ_min > 0` | — | valid inputs must be accepted; a clamped beam has no rigid mode |
| C-T | a linear twin's tip agrees with its nonlinear run | rel. 1e-2 | the load keeps the strain at ~2.5e-4; second-order effects are O(strain) |
| C-A | the converged references agree with Timoshenko | rel. 0.10 | beam theory vs 3D elasticity at `L/H = 4` (clamped-end warping, Poisson) is a several-percent effect; at `L/H = 16, 40` it should be well inside |
| C-L1 | P2 on `h = .25` is within 5 % of the reference at every `ν` | `r ≥ .95` | P2 converges at `h²` in energy on the smooth bending field; the h-refined reference differs by the `h = .25 → .125` step |
| C-L2 | locking is monotone: `r` is non-increasing in `ν` for P1 (`h = .5, .25`) and P2 (`h = .5`) | tol 1e-3 | volumetric locking stiffens with `λ/μ`; a non-monotone `r` would mean the reference itself moved |
| C-B | every tip ratio lies in `(0, 1.05)` | — | a coarse conforming space is stiffer than the converged one (energy minimisation); 5 % allows the reference's own error |
| C-H | homogeneous cube: `σ` and `l` match the exact state, `σ` uniform | rel. 1e-6 | the exact solution is in the space; the residual is the Newton tolerance (`grad_norm_tol 1e-10`) |
| C-N | homogeneous cube converges in a bounded number of Newton iterations at every `ν` | ≤ 20 | the state is a single Newton basin; iteration growth with `ν` measures the conditioning |
| C-F | affine cube: `σ` matches the law's reference, `σ` uniform; a fibre of length 3 gives the same stress as the unit fibre | rel. 1e-6 | exact solution in the space; `HGODispersion` normalises the fibre |
| C-D (unit test) | every law: FD gradient/Hessian consistent; translation invariance; objective laws rotate forces/tangent (`R H Rᵀ`); linear laws' rotation energy `∝ θ⁴`; stress-free reference (except `ActiveFiber`); fibre laws frame-indifferent | 1e-5 (FD), 1e-9/1e-8/1e-7 (invariances), 2 % on the quartic ratio | second-order differences at `h = 1e-7` on O(1e4) energies; invariances hold to roundoff |

Reported, not thresholded (characterisation): the P1 tip ratios at every
`ν` and `h`, the thin-section and distorted-mesh ratios, `κ(K)` and its
growth with `ν`, aspect ratio and jitter, Newton counts, the fibre-reinforced
bending ratios.

## Amendment 1 — reference accuracy (declared 2026-09-14 before the refinements ran)

The independent review (rb-11-stage-review-20260913.md) qualified the
references: one finest P2 mesh is a *fine comparison*, not demonstrated
convergence, and the `.25 → .125` step estimates one increment only. One
bounded refinement per selected reference is added, same law, load and
mesh, one polynomial order higher (P3), for the worst near-incompressible
reference (`locking-ref-nu0.4999`), the ν = .3 control (`locking-ref-nu0.3`),
the thinnest section (`thin-ref-H0.1`) and the fibre-reinforced reference
(`anisotropic-bending-ref`).

| Id | Check | Threshold | Justification |
| --- | --- | --- | --- |
| C-REF | `|u_tip(P3) − u_tip(P2 ref)| / |u_tip(P3)|` for each selected reference | ≤ 1e-2 (an engineering criterion, materially below the 5 % adequacy target C-L1) | if the P2 reference moves by more than 1 % under p-refinement its remaining error is not small against the 5 % target and the affected C-L1 verdicts are reported as unresolved |

No further refinement is run whatever the outcome: a miss is reported as
reference uncertainty, and the affected accuracy claims stay unresolved.
The refinements run on candidate B (`identity-candidate-B.txt`); the P2
references they qualify ran on candidate A, shown bit-identical to B on
three representative nonlinear cases (`independence-check/`).
